# Event Taxonomy — Moné Synthetic Data

## Overview

Every transaction generated by the synthetic data system maps to an event from this taxonomy. Events are organized by financial behavior type, not by account type. The generator selects events based on persona profile, behavioral state, calendar position, and life events.
